# راه‌اندازی سامانه فروش سوزن

## فایل‌ها
- `needle/index.html`: پنل فارسی هنرجو، مدرس و مدیر
- `needle/schema.sql`: ساخت جداول پایگاه داده D1
- `functions/api/needle/[[path]].js`: API سمت سرور
- `functions/api/needle/`: مسیر API سامانه

## راه‌اندازی الزامی در Cloudflare Pages
این نسخه به پایگاه داده مرکزی Cloudflare D1 نیاز دارد. به‌دلیل اینکه شناسه حساب و مجوز ساخت منابع Cloudflare از طریق اتصال فعلی در دسترس نیست، ایجاد D1 و اتصال binding از داخل مخزن ممکن نیست؛ فایل SQL آماده است و فقط این اتصال یک‌باره باید در داشبورد Cloudflare انجام شود.

1. Cloudflare Dashboard → Workers & Pages → D1 SQL Database → Create database. نام پیشنهادی: `needle-sales`.
2. در دیتابیس تازه‌ساخته‌شده، محتوای `needle/schema.sql` را در بخش Console اجرا کنید.
3. Cloudflare Dashboard → Workers & Pages → Pages → پروژه متصل به همین مخزن → Settings → Functions → D1 database bindings.
4. یک binding با **Variable name دقیقاً `NEEDLE_DB`** بسازید و دیتابیس `needle-sales` را انتخاب کنید.
5. در همان پروژه، Settings → Variables and Secrets، یک secret با نام `NEEDLE_SETUP_KEY` بسازید. یک کلید تصادفی قوی انتخاب کنید و آن را در اختیار مدیر سامانه قرار دهید. این کلید فقط برای ساخت اولین حساب مدیر است.
6. پس از ذخیره تنظیمات، یک‌بار پروژه را دوباره Deploy کنید.
7. مسیر `/needle/` را باز کنید، «راه‌اندازی مدیر» را بزنید و با کلید مرحله ۵، نام، موبایل و رمز قوی مدیر را ثبت کنید. پس از ایجاد مدیر، راه‌اندازی اولیه قفل می‌شود.

## امکانات پیاده‌سازی‌شده
- ثبت‌نام هنرجو و ورود امن با نشست HttpOnly
- ایجاد حساب مدرس توسط مدیر
- ثبت سفارش توسط هنرجو یا مدرس
- پرداخت به حساب مدرس یا مؤسسه (مطابق تنظیمات)
- درصد سهم مؤسسه قابل ویرایش از ۰ تا ۱۰۰ درصد
- ذخیره نرخ سهم روی هر سفارش؛ تغییر نرخ فقط روی سفارش‌های بعدی اثر دارد
- ثبت رسید/شماره پیگیری پرداخت و تأیید یا رد توسط مدیر
- ثبت فاکتور خرید مدرس
- ثبت درخواست تسویه سهم مؤسسه و تأیید مدیر
- وضعیت خرید، آماده تحویل، تحویل و لغو سفارش
- گزارش تجمیعی فروش و سهم مدرس‌ها
- ثبت رویدادهای مدیریتی در جدول audit

## نکات عملیاتی مهم
- واحد مبالغ در رابط کاربری تومان است.
- پرداخت واقعی بانکی/درگاه به این نسخه متصل نیست؛ سامانه رسید و شماره پیگیری را ثبت می‌کند و مدیر آن را بررسی می‌کند.
- فایل رسید در این نسخه به‌صورت URL ثبت می‌شود؛ برای بارگذاری امن فایل باید فضای ذخیره‌سازی R2 و محدودیت حجم/نوع فایل اضافه شود.
- برای استفاده عمومی، مدیر باید حساب مدرس‌ها را ایجاد کند. ثبت‌نام عمومی فقط نقش هنرجو می‌سازد.
- برای حساب مدیر، رمز حداقل ۱۰ کاراکتر و برای مدرس/هنرجو حداقل ۸ کاراکتر انتخاب شود.
